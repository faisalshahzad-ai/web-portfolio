# Tsuchi Ceramics: Handcrafted Artisanal Homewares

A modern e-commerce website for a direct-to-consumer ceramics studio. It shows a full online-store experience: browsing, product details, cart, checkout, order tracking and customer account. Built as a front-end demo with sample product data.

## Features

- **Shop and search:** product catalogue with filters and a quick search window
- **Product pages:** image gallery, glaze switcher, 360-degree turntable view and a sticky purchase bar
- **Cart and checkout:** slide-out cart drawer, shipping estimator and a full checkout flow
- **Customer area:** account page and order tracking
- **Brand pages:** studio story, care guide and stockist locator
- **Responsive design:** works on phones, tablets and desktops

## Tech Stack

React 19, TypeScript, Vite, Tailwind CSS, Motion (animations), Lucide icons

## Run Locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Build for Production

```bash
npm run build
```

## Notes

- Product, order and stockist data are sample data in `src/data/mockData.ts`
- Checkout is a demo flow. No real payments are processed
- No API keys are required to run this project
